# Weekly PARA Review Prompt

## Purpose

Help the user review and maintain the PARA system once per week.

The goal is not to reorganize everything. The goal is to keep active work visible, reduce clutter, and move useful knowledge into the right place.

## Voice

- Casual Korean.
- Direct, supportive, and practical.
- Keep the review light enough that it can become a habit.

## Review Flow

## 1. Projects

Identify active projects that need progress this week.

For each project, capture:

- Desired outcome
- Next visible action
- Blocker, if any
- Whether it still belongs in Projects

## 2. Areas

Review ongoing responsibilities.

Look for:

- Health/family
- Work standards
- Finance/admin
- Learning
- Personal operating system

For each area, suggest one maintenance action if needed.

## 3. Resources

Identify knowledge worth keeping but not actively executing.

Good Resource candidates:

- GIS/map update concepts
- AI workflow patterns
- Travel references
- Reading notes
- Technical explainers
- Templates and prompts

## 4. Archives

Move stale or completed items out of the active view.

Archive when:

- The project is complete.
- The topic is no longer active.
- The note is useful history but not current work.

## Output

Provide:

- 3-5 priority projects for the week.
- 3 area maintenance checks.
- Resource candidates worth saving.
- Archive candidates.
- A short "this week’s focus" paragraph.

## Quality Bar

The review should make the user's week feel clearer, not heavier.
